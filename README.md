# Casa em Camadas

Um catálogo editorial de peças para casa, com filtros simples e descrições próprias para explorar composição e organização de conteúdo.

## Como executar

Abra `index.html` em um navegador moderno. O projeto funciona localmente, sem instalação ou conexão externa.

## Nota sobre a versão pública

Este exercício acadêmico foi desenvolvido individualmente antes desta versão. A versão pública foi redesenhada e refatorada em 2026 com assistência de IA. Não inclui enunciados, boilerplate ou ativos de terceiros; os dados apresentados são fictícios.

## Verificação manual

1. Abra `index.html` em um navegador atualizado ou acesse a demonstração pública abaixo.
2. Teste os filtros, buscas, botões ou entradas disponíveis e confira se a página atualiza os resultados. Em páginas sem controles, confira a leitura e a navegação.
3. Percorra links e controles com o teclado (`Tab` e `Enter`) e confirme que o foco está visível.
4. Confira a página em 320, 768, 1024 e 1440 px; não deve haver rolagem horizontal.
